# puma-tx-fst-pilot
Pilot analysis to look for differences in allele frequencies between 2013 and 2024 TX Purple Martin populations

## files
BARS_PUMA_alignment.csv -> details order of PUMA scaffolds according to Barn Swallow genome
sequence_report.tsv -> key to rename EDG-style scaffolds ("scaffold*") to RWH-style ("JAK*"); includes scaffold lengths
